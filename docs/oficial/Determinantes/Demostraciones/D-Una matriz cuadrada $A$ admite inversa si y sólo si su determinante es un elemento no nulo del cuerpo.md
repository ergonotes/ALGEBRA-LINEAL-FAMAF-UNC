**Corolario:** Si $A \in M_{n \times n}(\mathbb{K})$ es invertible
$$\Rightarrow \det(A) \neq 0 \ \ \text{ y } \ \ \det(A^{-1}) = \frac{1}{\det(A)}$$

****
**Demostración.** Si $A$ es invertible $\Rightarrow A \cdot A^{-1} = \text{Id}$
$$\Rightarrow \det(A A^{-1}) = \det(\text{Id}) = 1$$
$$\det(A) \cdot \det(A^{-1}) = 1 \Rightarrow \det(A) \neq 0 \text{ y } \det(A^{-1}) = \frac{1}{\det(A)}$$
