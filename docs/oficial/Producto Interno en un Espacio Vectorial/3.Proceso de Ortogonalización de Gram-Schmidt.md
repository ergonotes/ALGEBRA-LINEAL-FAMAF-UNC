### **[[D-Todo sistema ortogonal de vectores no nulos en un E.V con producto interno, puede transformarse en un sistema ortonormal]]**
**Enunciado.** Sea $V$ un espacio vectorial sobre $\mathbb{R}$ provisto de un producto interno. Si $X = \{v_1, \dots, v_r\}$ es un conjunto **ortogonal** de vectores no nulos ($v_i \neq 0$ para todo $i$), entonces el conjunto $X'$ formado por los vectores normalizados:

$$X' = \left\{ \frac{v_1}{\|v_1\|}, \dots, \frac{v_r}{\|v_r\|} \right\}$$

es un conjunto **ortonormal**.
****
#### **Algoritmo**
Es un algoritmo que permite pasar de una base cualquiera del espacio $\{v_1, \dots, v_n\} \in V$ a una base ortogonal de $V$ $\{w_1, \dots, w_n\} \in V$ con la importante propiedad que para cualquier $m, \ \  1 \le m \le n$, el subespacio generado por $\{v_1, \dots, v_m\}$ es el mismo que generan $\{w_1, \dots, w_m\}$.
****
El proceso es la herramienta que usamos para tomar un conjunto de vectores "desordenados" (que apuntan en direcciones arbitrarias) y "enderezarlos" para construir un conjunto de vectores que sean perfectamente perpendiculares entre sí, sin perder el espacio que representaban originalmente.
**Paso 1.**
Tomamos el primer vector original y lo declaramos como nuestro primer vector ortogonal.

$$u_1 = v_1$$

**Paso 2.**
Tomamos el segundo vector original ($v_2$). Para hacerlo ortogonal a $u_1$, le restamos la **proyección ortogonal** de $v_2$ sobre la dirección de $u_1$.

$$u_2 = v_2 - \text{proy}_{u_1}(v_2)$$

Aplicando la fórmula de proyección que ya conocemos:

$$u_2 = v_2 - \frac{\langle v_2, u_1 \rangle}{\|u_1\|^2} u_1$$
 Y vemos también que $u_1 \perp u_2$
**Paso 3.**
Tomamos el tercer vector original generado ($v_3$). Ahora debemos limpiarlo de las direcciones de los _dos_ vectores ortogonales que ya construimos ($u_1$ y $u_2$). Le restamos la proyección de $v_3$ sobre $u_1$ y la proyección de $v_3$ sobre $u_2$:

$$u_3 = v_3 - \frac{\langle v_3, u_1 \rangle}{\|u_1\|^2} u_1 - \frac{\langle v_3, u_2 \rangle}{\|u_2\|^2} u_2$$

**Paso $k$.**
El proceso continúa de la misma manera para cualquier vector $v_k$. Al vector original se le restan las proyecciones sobre **todos** los vectores ortogonales $u_i$ construidos en los pasos anteriores:

$$u_k = v_k - \sum_{i=1}^{k-1} \frac{\langle v_k, u_i \rangle}{\|u_i\|^2} u_i$$

#### **Ortonormalización (Opcional)**
A menudo, se pide una base **ortonormal**.
Si necesitamos esto, tomamos la nueva base ortogonal $\{u_1, u_2, \dots, u_n\}$ y dividimos cada vector por su propia norma:

$$e_1 = \frac{u_1}{\|u_1\|}, \quad e_2 = \frac{u_2}{\|u_2\|}, \quad \dots, \quad e_n = \frac{u_n}{\|u_n\|}$$

El conjunto resultante $E = \{e_1, e_2, \dots, e_n\}$ es la base ortonormal.
****
### **[[D-Ortogonalización de Gram-Schmidt]]**
**Teorema.** Sea $V$ un espacio vectorial sobre $\mathbb{R}$ provisto de un producto interno $\langle \cdot, \cdot \rangle$ y de dimensión finita ($\dim V < \infty$).

Sea $\{v_1, \dots, v_n\}$ una base de $V$.

Entonces, existe una base ortogonal de $V$ formada por los vectores $\{w_1, \dots, w_n\}$, tal que el subespacio generado por los primeros $m$ vectores originales $\{v_1, \dots, v_m\}$ es el mismo que el espacio generado por los nuevos vectores $\{w_1, \dots, w_m\}$ para todo $m = 1, \dots, n$.

Explícitamente, los vectores de esta base están dados por la siguiente construcción recurrente:

$$w_1 = v_1$$
$$w_2 = v_2 - \frac{\langle v_2, w_1 \rangle}{\langle w_1, w_1 \rangle} w_1$$
$$w_3 = v_3 - \frac{\langle v_3, w_1 \rangle}{\langle w_1, w_1 \rangle} w_1 - \frac{\langle v_3, w_2 \rangle}{\langle w_2, w_2 \rangle} w_2 \quad \left(\text{Es decir, } v_3 - \text{proy}_{w_1}(v_3) - \text{proy}_{w_2}(v_3)\right)$$
$$w_n = v_n - \sum_{j=1}^{n-1} \frac{\langle v_n, w_j \rangle}{\langle w_j, w_j \rangle} w_j$$
****
### **[[D-Existencia de una Base Ortogonal en Subespacios]]**
**Corolario.** Sea $V$ un espacio vectorial (de dimensión finita) provisto de un producto interno. Si $W$ es un subespacio vectorial de $V$, entonces existe una base ortogonal para $W$.
